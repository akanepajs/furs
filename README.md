# furs.kanepajs.eu

Public figures for the EU fur phase-out and transition-costs study.

## Contents

- `index.html` / `enclosure_space_figure.html`: minimum enclosure or cage floor area
  plus water-pool area per adult mink, by standard, comparing captive-animal and zoo
  standards (US AZA, Switzerland, Austria, German keeping guidance), Germany's binding
  fur-farming statute, and the current EU legal cage and reform proposals (Finland draft
  decree, Ecorys / EC proposed measures), read against the EFSA 9519 welfare verdict.
  Self-contained (inline SVG + CSS + JS, no external dependencies); every value verified
  against a primary source, with an APA source list on the page.
- `CNAME`: custom domain for GitHub Pages.

Prepared with Claude Code.
